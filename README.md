# RoSy — Rhythm of Swing-by
<img width="396" height="197" alt="image" src="https://github.com/user-attachments/assets/42e559f6-75cf-4427-af38-67a142484cbd" />
> 회전하는 지구에서 로켓을 발사하고, 행성의 중력을 이용해 스윙바이하며 목적지까지 도달하라.

RoSy는 **타이밍 + 궤도 + 스윙바이**를 핵심으로 하는 우주 항법 퍼즐 게임입니다. 로켓을 직접 조종하는 게임이 아닙니다. 지구의 자전을 보면서 "언제, 어느 방향으로, 얼마나 가속할지"를 정하고, 그 결과 만들어지는 궤도를 지켜보게 됩니다.

## 실행 방법

설치나 빌드 없이 `index.html` 파일 하나로 동작합니다.

1. 저장소를 받습니다.
2. `index.html`을 브라우저(Chrome, Edge, Firefox, Safari)로 엽니다.

> 폰트는 Google Fonts에서 불러오므로, 오프라인이면 시스템 기본 폰트로 표시됩니다. 소리는 브라우저 정책상 첫 클릭 이후부터 납니다.

## 조작

| 입력 | 동작 |
|---|---|
| 클릭 / `Space` | 로켓 발사 (누르고 있으면 진행 방향으로 엔진 분사) |
| `←` `→` / `A` `D` / 마우스 휠 | 발사 전 발사각 조정 (±70°) |
| `P` | 궤도 예측 표시 전환 (끔 / 짧게 3초 / 길게 9초) |
| `R` | 스테이지 다시 시작 |
| `M` | 소리 켜기/끄기 |
| `Esc` | 스테이지 선택 |
| `Enter` | 미션 시작 / 다음 스테이지 |

터치 기기에서는 화면을 누르면 발사·분사되고, 하단 ◀ ▶ 버튼으로 발사각을 조정합니다.

## 게임 시스템

### 발사 타이밍
로켓은 지구 표면의 발사대에 붙어 지구와 함께 회전합니다.
- **발사 방향** = 지표에 수직인 방향 + 발사각
- **초기 속도** = 발사 속도 + 지구 자전에 의한 접선 속도

같은 발사각이라도 누르는 순간에 따라 궤도가 달라집니다. 지구가 1/4바퀴 돌 때마다 눈금이 빛나고 틱 소리가 나며, 이것이 발사의 리듬이 됩니다.

### 중력과 궤도
로켓은 모든 행성의 중력(역제곱 법칙)을 받습니다. 행성은 공전하며 움직이므로 발사 시점에 따라 행성의 위치도 달라집니다.

### 스윙바이
행성의 **중력권**(점선 원)에 들어갔다 나올 때 진행 방향이 **25° 이상** 꺾이면 스윙바이로 판정합니다. 움직이는 행성 곁을 지나면 방향뿐 아니라 **속도도 실제로 빨라지거나 느려집니다.**

### 연료(Δv)
엔진은 누르고 있는 동안만 진행 방향으로 가속합니다. 연료는 스테이지마다 정해진 Δv로 제한됩니다.

### 실패 조건
- 목적지가 아닌 행성이나 소행성과 충돌
- 화면 밖으로 너무 멀리 벗어남 (우주 미아)
- 60초 안에 도착하지 못함

## 구조

모든 코드가 `index.html` 한 파일에 들어 있습니다.

- **시뮬레이션** (`/*SIM-BEGIN*/` ~ `/*SIM-END*/`): 스테이지 데이터(`STAGES`), 천체 위치 계산, 고정 스텝(1/240초) 물리 적분, 충돌·도착·스윙바이 판정. DOM에 의존하지 않는 순수 로직입니다.
- **게임 레이어**: Canvas 2D 렌더링, HUD, 입력 처리, Web Audio 효과음.

### 스테이지 추가·조정
`STAGES` 배열에 객체를 추가하거나 값을 바꾸면 됩니다.

```js
{
  name: '스테이지 이름', target: 'mars',          // 목적지 천체 id
  brief: '시작할 때 보여줄 설명',
  earth: { x: 200, y: 450, w: 0.5, a0: -2.4 },     // 위치, 자전 속도(rad/s), 초기 각도
  v0: 165, fuel: 260,                              // 발사 속도, 연료(Δv)
  swingGoal: 0, fuelStar: 0.6,                     // 별 조건
  bodies: [
    { id: 'mars', name: '화성', kind: 'planet', r: 30, mu: 6e5,
      color: '#E0855A', dark: '#5E2414',
      orbit: { cx: 1100, cy: 450, R: 90, w: 0.25, phase: 0 } }  // 또는 고정 위치 x, y
  ],
  belts: [ { x1, y1, x2, y2, hw, seed } ]          // 통과할 수 없는 소행성대
}
```

월드 좌표계는 1600 × 900이며, 화면 크기에 맞춰 자동으로 확대·축소됩니다.
